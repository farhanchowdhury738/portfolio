# Personal Portfolio

A modern and responsive personal portfolio website showcasing my education, projects, skills, experience, blog, and contact information.

## Features

- Responsive design
- Dark / Light mode
- Mobile navigation
- Projects section with View All / Show Less
- Resume and education section
- Blog section
- Contact section
- Responsive sidebar
- Tailwind CSS
- Lucide Icons
